## 回顾范围与口径

- 正式月度窗口：北京时间 `2026-07-01T00:00:00` 至
  `2026-07-31T23:59:59`，含首尾。
- 时间轴使用代表纸面记录的比赛 `kickoff_time`，不使用快照
  `created_at`。
- 前半月：`2026-07-01T00:00:00` 至 `2026-07-16T23:59:59`。
- 后半月：`2026-07-17T00:00:00` 至 `2026-07-31T23:59:59`。
- 快照版本：`paper_confidence_v1`。
- 主查询使用 Web API `/api/paper-snapshot-review`，并对
  `automation`、`manual_record`、`historical_backfill` 显式传入
  `snapshot_source`。
- CLI `records snapshot-report` 用于交叉核对总览、来源分布、
  `market_type + line_bucket` 和 `market_type + stake_bucket`。
- 另以只读方式查询本地 SQLite，检查来源全集、重复、关联记录、收益、
  赔率、手数、版本和时间边界。未执行回填，也未写入数据库。
