## 回顾范围与查询口径

- 本次为原定 2026-08-15 的轻量半月回顾，为覆盖完整自然半月，于
  2026-08-16 执行。
- 主窗口：北京时间 `2026-08-01T00:00:00` 至
  `2026-08-15T23:59:59`，含首尾。
- 第一段：北京时间 `2026-08-01T00:00:00` 至
  `2026-08-07T23:59:59`。
- 第二段：北京时间 `2026-08-08T00:00:00` 至
  `2026-08-15T23:59:59`。
- 时间轴使用代表纸面记录的比赛 `kickoff_time`，不使用快照
  `created_at`；本文时间均按北京时间解释和展示。
- 快照版本：`paper_confidence_v1`。
- 主查询使用 Web API `/api/paper-snapshot-review`，分别显式传入
  `snapshot_source=all`、`automation`、`manual_record` 和
  `historical_backfill`。
- All 模式按 `group_key` 去重，优先级为 `automation > manual_record >
  其他来源 > historical_backfill`；同一优先级再按较新 `created_at`、
  较大 ID 选择。
- CLI `records snapshot-report` 用于交叉核对总览、来源、
  `market_type + stake_bucket` 和 `market_type + line_bucket`。本窗口
  来源间无重复，因此 CLI 不传 `--source` 的 376 组结果可作为 All 合并
  参考；该行为本身并没有变成 API All 去重模式。
- 另以 SQLite `mode=ro` 只读连接检查本地真实数据库。未执行写入式
  `historical_backfill`，未修改代码、策略或数据库。
