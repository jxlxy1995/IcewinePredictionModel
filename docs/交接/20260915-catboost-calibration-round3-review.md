## 结论

**本轮不支持替换模型，也没有新增信号通过预设发现期门槛。** CatBoost 概率校准降低了亚盘整体概率误差，但主要表现为概率向约50%收缩，未形成足够的可执行优势。纳入全部结算结果的模型在部分后期方向上盈利，但发现期表现不足，不能将后期盈利改写为预先合格的信号。

这轮只比较第二轮原始 CatBoost、时间外预测校准 CatBoost、五类结算 CatBoost。未触碰实际旧HGB模型，不应把研究模型的诊断外推为旧实战信号失效。

## 方法一：时间外预测的概率校准

复用第二轮固定CatBoost参数：300次迭代、深度4、学习率0.05、L2=5、种子42。对原始概率先取logit，再用 `LogisticRegression(C=1)` 拟合一维sigmoid映射。

校准只使用更早月份的时间外预测：例如7月校准器只使用3—6月预测；每条预测来自未训练过该场比赛的月度模型。3月初始预测额外使用3月1日前至少3小时的比赛训练。校准每场只取一条代表报价，不把六个高度相关的时点当六场比赛。

校准数据及当前模型训练数据都在预测月之前。二者可以共享较早比赛，因为校准输入使用的是当时未见该场的预测，而非最终模型在训练集上的预测。这里校准映射跨月度重训模型迁移，仍可能受到赛季变化、训练规模和模型分布变化影响。

各市场每月独立拟合，仍只使用全赢/全输二分类标签；没有用后期真实结果校准同月预测。

### 概率误差

后期A组，以所有代表盘口为半球刻度的比赛计算Brier误差，越低越好：

| 方法 | 亚盘665场 | 大小球712场 |
| --- | ---: | ---: |
| 原始CatBoost | 0.25862 | 0.24981 |
| sigmoid校准 | 0.25059 | 0.24993 |
| 市场归一化隐含概率 | 0.25099 | 0.24965 |
| 固定50%数学参考 | 0.25000 | 0.25000 |

亚盘校准减原始Brier为-0.00804，配对日期聚类95%描述性区间[-0.01342,-0.00247]；大小球差值+0.00011，区间[-0.00441,+0.00423]。未校正反复研究和多重比较，不作推广意义上的显著性承诺。

A组7—9月校准斜率约0.064—0.096，明显小于1；C约0.101—0.176。这表明在这套全局校准定义下，原始概率幅度被大幅压缩。亚盘误差改善主要来自抑制激进预测，不能据此声称模型学到了更多可盈利信息；固定50%的简单参考也提醒我们，接近0.25并不自动代表有选场能力。

### 规则效果

新增校准方法的28条规则全部未通过发现期门槛：单条最多只有4场发现期样本，仅2条出现过发现期入选比赛。

原始CatBoost主队平手盘0.06规则发现期53场，校准后仅3场，后期A仅1场。因此不能因原规则回测好看而降低校准后的阈值来补足推荐数量。校准概率差与原始概率差的数值分布不同，但本轮未在看到结果后重新搜索阈值。

## 方法二：完整结算结果建模

将二分类目标改为主队方向或大球方向的五类结果：全赢、赢半、走盘、输半、全输。使用固定CatBoost参数与 `MultiClass` 损失，保留所有可结算训练样本，而不只使用全赢/全输。

例如A组7月亚盘训练为5,034场、大小球5,068场；此前二分类分别为3,929和4,169场。增加的数据主要来自原先排除的半赢、半输和走盘。

不同盘口不可能出现全部五类结果。预测时根据已知盘口，将不可能的结果概率设零并重新归一化，例如2.50球不可能走盘或半赢半输。该限制由盘口规则确定，与真实赛果无关，不是根据赛后结果过滤。

两侧预期收益分别为：

```text
方向0 EV = P(全赢)*(赔率0-1) + P(赢半)*(赔率0-1)/2
           - P(输半)/2 - P(全输)
方向1 EV = P(全输)*(赔率1-1) + P(输半)*(赔率1-1)/2
           - P(赢半)/2 - P(全赢)
```

选择EV更高的一侧，仍需通过六时点一致性及最小EV条件。该模型优化的是结算类别的对数损失，再换算EV，并非直接最大化回测收益。阈值0.06/0.10在这里是单位预期收益，不能与二分类概率差等同解释。

后期按时点加权，不可能结果的平均原始概率质量约6.4%—6.6%。归一化虽确保结算逻辑正确，这一比例也说明五分类本身未完全学好盘口允许的结果结构，当前方法仍有模型设定方面的局限。

| --- | ---: | ---: | ---: | ---: |
| 低盘口大球，EV0.06 | 104 / -9.54% | 63 / +13.81% | 63 / +13.84% | 80 / +16.02% |
| 2.50大球，EV0.06 | 82 / -17.11% | 75 / +7.95% | 76 / +6.59% | 65 / +4.02% |

前三项在后期有正收益，但发现期均亏损；第四项发现期样本不足。它们都是未通过门槛的事后诊断，不是新晋候选，也没有据此生成推荐。

五类结算模型全部28条规则未通过发现期门槛。客队让球方向EV0.06虽有43场、+6.38%，但只有一个月份同时达到样本和盈利要求，仍未通过；没有为它放宽月份要求。

模型A组半球刻度大小球Brier为0.24876，原始CatBoost为0.24981，点估计略有改善；两者配对差值95%区间[-0.00444,+0.00220]跨零。C组则为0.24952，略差于原始0.24931，不能称为稳定改善。

## 对现有系统的含义

1. 当前证据支持继续使用现有已跟踪的模型和信号，没有研究结果足以要求替换。
2. 全局校准可以降低部分过度自信，但降低概率误差与产生可盈利推荐是两个问题。不能把校准后信号减少解释为应该放宽阈值。
3. 全结算目标解决了二分类标签遗漏半赢/走盘的问题，但数据更多、目标更完整并不保证收益更好。
4. 同一段历史已连续研究多轮，继续根据后期结果筛选很容易扩大选择偏差。后续优先依靠新增样本或有明确依据的新信息，而不是反复重排这批历史赢家。
5. 所有后续研究结论只作为审核材料。生产模型替换、新信号加入推荐流程或纸面链路，都必须先取得用户明确确认。
